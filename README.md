### Topics Explored
* **Computer Architecture:** Input, Processing, Output, and Storage (IPOS), hardware vs. software classification, and embedded systems.
* **Command-Line Interface:** File navigation, safe redirection ( vs. ), flags, pipes (), and package managers.
* **Operating Systems:** Process IDs (PIDs), absolute vs. relative paths, owner permissions (), and OS resource management.
* **Program Execution & Data:** Compilers vs. interpreters, binary/hexadecimal conversions, and ASCII/UTF-8 text encoding.
* **Collaboration & Networking:** Git staging/committing, feature branches, Pull Requests, LAN/MAN/WAN, DNS, and HTTP/TCP/IP.

### How to Run the Python Number Converter
```bash
cd mission-05-numbers-data
python3 number_converter.py
```
Enter any positive decimal integer when prompted to view its binary (`0b...`) and hexadecimal (`0x...`) representations.
