## 4. My understanding
Every computing task follows the IPOS cycle: hardware devices capture raw user actions as input, the CPU and RAM process instructions, output peripherals display feedback to the user, and non-volatile storage retains the result permanently.

### Task 1.1 — Tracing an Activity Using IPOS (Writing & Saving a Code File)
| Stage | What happens in your example? | Possible hardware / component |
| :--- | :--- | :--- |
| **Input** | Keystrokes are pressed to type Python code into the editor and trigger the save shortcut. | Keyboard |
| **Processing** | The OS translates key scan codes into characters, renders text in the editor buffer in RAM, and encodes bytes for saving. | CPU and RAM |
| **Output** | The typed characters and syntax highlighting appear immediately on the display. | Monitor / Screen |
| **Storage** | The file bytes are written permanently to the file system so the code persists after power-off. | Solid-State Drive (SSD) |
